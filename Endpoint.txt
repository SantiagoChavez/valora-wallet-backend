=== MÓDULO AUTH (AUTENTICACIÓN) ===

Ruta: /auth/register
Operacion: POST
Archivo Json de entrada:
{
  "email": "string (email format)",
  "password": "string (min 8 chars)",
  "firstName": "string",
  "lastName": "string",
  "dateOfBirth": "string (DD/MM/YYYY)",
  "phone": "string",
  "country": "string",
  "du": "string"
}
Respuesta: 201 Created
Estructura Json:
{
  "success": "boolean",
  "data": {
    "user": {
      "id": "string (uuid)",
      "email": "string",
      "firstName": "string",
      "lastName": "string",
      "phone": "string",
      "country": "string",
      "du": "string",
      "createdAt": "string (iso date)"
    },
    "wallet": {
      "id": "string (uuid)",
      "cvu": "string",
      "alias": "string"
    },
    "token": "string (jwt)"
  }
}
