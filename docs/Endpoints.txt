# Guia de Endpoints para Insomnia / REST Client

Esta es la guia paso a paso para probar tu backend localmente utilizando **Insomnia** o cualquier cliente HTTP.

> ⚠️ **IMPORTANTE: Configuracion de Base de Datos y Seguridad TLS**
> Antes de empezar, asegurate de que tu archivo `.env` contenga la siguiente variable al final. Esto soluciona el error `self-signed certificate` con la base de datos de Railway.
> *Advertencia: Esto deshabilita la verificación TLS estricta. Utilízalo únicamente para desarrollo local, o si el proveedor proxy remoto (Railway) requiere tolerancia a certificados auto-firmados.*
> ```env
> DB_SSL_REJECT_UNAUTHORIZED=false
> ```

---

## 0. Utilidades (`/health`)

### 0.1 Verificar Estado del Servidor
*   **Metodo:** `GET`
*   **URL:** `http://localhost:3000/health`
*   **Respuesta de Exito (200 OK):**
    ```json
    {
      "status": "UP",
      "timestamp": "2023-10-25T10:00:00.000Z"
    }
    ```

## 1. Autenticacion (`/auth`)

### 1.1 Registrar un Usuario
*   **Metodo:** `POST`
*   **URL:** `http://localhost:3000/auth/register`
*   **Request Body (JSON):**
    ```json
    {
      "email": "carlos.prueba@email.com",
      "password": "PasswordSeguro123!",
      "firstName": "Carlos",
      "lastName": "Lopez",
      "dateOfBirth": "10/10/1995",
      "phone": "+525512345678",
      "country": "AR",
      "du": "12345678"
    }
    ```
*   **Respuesta de Exito (201 Created):**
    ```json
    {
      "success": true,
      "data": {
        "token": "eyJhbGciOiJIUzI1...",
        "user": {
          "id": "uuid",
          "email": "carlos.prueba@email.com",
          "firstName": "Carlos",
          "lastName": "Lopez",
          "dateOfBirth": "10/10/1995",
          "phone": "+525512345678",
          "country": "AR",
          "du": "12345678"
        },
        "wallet": {
          "id": "uuid-wallet",
          "cvu": "1234567890123456789012",
          "alias": "carlos.lopez.valora"
        }
      }
    }
    ```
*   **Respuesta de Error (400 Bad Request - Email en uso):**
    ```json
    {
      "success": false,
      "error": "DuplicateEmailError",
      "message": "El correo electrónico ya se encuentra registrado"
    }
    ```

## 2. Billetera (`/wallet`)

### 2.1 Actualizar Alias 🔒
*   **Metodo:** `PUT`
*   **URL:** `http://localhost:3000/wallet/alias`
*   **Headers:** `Authorization: Bearer <TOKEN>`
*   **Request Body (JSON):**
    ```json
    {
      "alias": "mi.nuevo.alias"
    }
    ```
*   **Respuesta de Exito (200 OK):**
    ```json
    {
      "success": true,
      "data": {
        "wallet": {
          "id": "uuid-wallet",
          "cvu": "1234567890123456789012",
          "alias": "mi.nuevo.alias"
        }
      },
      "message": "Alias actualizado correctamente."
    }
    ```
*   **Respuesta de Error (409 Conflict - Alias ocupado):**
    ```json
    {
      "success": false,
      "error": "DuplicateAliasError",
      "message": "Este alias ya está en uso por otro usuario."
    }
    ```

## 3. Transacciones (`/transactions`)

### 3.1 Realizar un Deposito 🔒
*   **Metodo:** `POST`
*   **URL:** `http://localhost:3000/transactions/deposit`
*   **Request Body (JSON):**
    ```json
    {
      "currency": "USD",
      "amount": 500
    }
    ```
*   **Respuesta de Exito (200 OK):**
    ```json
    {
      "success": true,
      "data": {
        "id": "uuid-tx",
        "walletId": "uuid-wallet",
        "transactionType": "DEPOSIT",
        "sourceCurrency": null,
        "targetCurrency": "USD",
        "sourceAmount": null,
        "targetAmount": 500,
        "exchangeRate": null,
        "resultingBalance": 500,
        "createdAt": "2023-10-25T10:00:00.000Z"
      }
    }
    ```

### 3.2 Realizar un Exchange 🔒
*   **Metodo:** `POST`
*   **URL:** `http://localhost:3000/transactions/exchange`
*   **Request Body (JSON):**
    ```json
    {
      "fromCurrency": "USD",
      "toCurrency": "ARS",
      "amount": 100
    }
    ```
*   **Respuesta de Exito (200 OK):**
    ```json
    {
      "success": true,
      "data": {
        "id": "uuid-tx",
        "walletId": "uuid-wallet",
        "transactionType": "EXCHANGE",
        "sourceCurrency": "USD",
        "targetCurrency": "ARS",
        "sourceAmount": 100,
        "targetAmount": 105050,
        "exchangeRate": 1050.50,
        "resultingBalance": 400,
        "createdAt": "2023-10-25T10:05:00.000Z"
      }
    }
    ```
*   **Respuesta de Error (400 Bad Request - Sin fondos):**
    ```json
    {
      "success": false,
      "error": "INSUFFICIENT_FUNDS",
      "message": "Saldo insuficiente para realizar la operación."
    }
    ```

## 4. Asistente Financiero (Chatbot)

### 4.1 Enviar Mensaje a la IA 🔒
*   **Metodo:** `POST`
*   **URL:** `http://localhost:3000/chatbot/message`
*   **Headers:** `Authorization: Bearer <TOKEN>`
*   **Request Body (JSON):**
    ```json
    {
      "message": "¿Me alcanza el saldo para comprar un café de 5 euros?"
    }
    ```
*   **Respuesta de Exito (200 OK):**
    ```json
    {
      "success": true,
      "data": {
        "reply": "Si tienes saldo suficiente. Actualmente cuentas con 55 EUR en tu billetera."
      }
    }
    ```
*   **Respuesta de Error (500 Internal Server Error - Falla IA):**
    ```json
    {
      "success": false,
      "error": "InternalServerError",
      "message": "Error interno del servidor. Por favor, inténtelo de nuevo más tarde."
    }
    ```
